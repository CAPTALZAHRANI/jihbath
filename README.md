# جِهْبَاذ · JIHBATH

أداة تتحقق من الآيات والأحاديث والأقوال المنسوبة في المحتوى الدعوي، عربيًا ومترجمًا، وتُصدر تقريرًا بحالة كل ادعاء ومصدره.

مشاركة في **تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي 2026** — المسار 04: أدوات المعرفة والتحقق لتمكين المعرّفين بالإسلام.

> الأداة تنقل أحكام أهل العلم منسوبة لقائليها، ولا تُفتي ولا تجتهد في الحكم.

## حالات التحقق

| الحالة | المعنى |
| --- | --- |
| ✅ ثابت ومطابق | وُجد في المصدر بلفظه |
| 🟠 ثابت بلفظ مختلف | وُجد، والفروق مُبرزة على مستوى الكلمة |
| 🔴 لا يصح | بحكم أهل العلم، مع عبارة الحكم حرفيًا |
| ⚫ لم يُعثر عليه | لا يوجد في المصادر المتاحة |
| 🔵 يحتاج مراجعة مختص | خلاف، أو حالة شخصية، أو حكم غير صريح |
