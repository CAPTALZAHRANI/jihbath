# جِهْبَاذ · JIHBATH

أداة تتحقق من الآيات والأحاديث والأقوال المنسوبة في المحتوى الدعوي، عربيًا ومترجمًا، وتُصدر تقريرًا بحالة كل ادعاء ومصدره.

مشاركة في **تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي 2026**، المسار 04: أدوات المعرفة والتحقق لتمكين المعرّفين بالإسلام.

**الرابط الحي:** https://jihbath-production.up.railway.app

> الأداة تنقل أحكام أهل العلم منسوبة لقائليها، ولا تُفتي ولا تجتهد في الحكم.

**النتائج:** ‏32/32 حالة في مجموعة الاختبار الشاملة · 0 ادعاء ثابت بلا مصدر · 7/7 امتناع صحيح عن نسبة المختلق · 5/5 إحالة صحيحة لأسئلة الفتوى. التفاصيل في [doc/test-results.md](doc/test-results.md).

## للمحكّم: تجربة سريعة

أسرع طريق هو **الرابط الحي**: الصق نصًا أو اضغط «جرّب نصًّا نموذجيًّا».

وللتشغيل المحلي (Node.js 20 أو أحدث):

```
npm install
npm run build
npm run fetch:quran
npm run build:quran
npm run fetch:quranenc
npm run build:quranenc
npm start
```

ثم افتح http://localhost:3000. بهذا يعمل التحقق من القرآن بالعربية والإنجليزية (فهارس محلية)، ومن الحديث (الدرر السنية، مباشرة)، والإحالة في أسئلة الفتوى.

**تنبيه بشأن موسوعة الأحاديث النبوية (HadeethEnc):** لا يُرفع محتوى الموسوعة إلى هذا المستودع احترامًا لحقوقها، بل يُجلب من واجهتها الرسمية بسكربت. الجلب الكامل (العربية والإنجليزية) يستغرق قرابة ساعة لأنه يحترم حدود الطلبات. لتجربة أسرع، اجلب العربية وحدها:

```
HE_LANGS=ar npm run fetch:hadeeth
npm run build:hadeeth
npm run build:meaning
```

(في PowerShell: `$env:HE_LANGS="ar"; npm run fetch:hadeeth`)

وبدون هذه الخطوة يعمل المنتج كاملًا، ويُفقد فقط المسار الثاني للأحاديث والتحقق من المحتوى الإنجليزي.

## حالات التحقق

| الحالة | المعنى |
| --- | --- |
| ✅ ثابت ومطابق | وُجد في المصدر بلفظه |
| 🟠 ثابت بلفظ مختلف | وُجد، والفروق مُبرزة كلمةً كلمة |
| 🔴 لا يصح | بحكم أهل العلم، مع عبارة الحكم حرفيًا |
| ⚫ لم يُعثر عليه | لا يوجد في المصادر المتاحة |
| 🔵 يحتاج مراجعة مختص | خلاف بين الأحكام، أو حكم غير صريح، أو تشابه في المعنى دون جزم |
| 🟣 خارج نطاق التحقق: يُحال إلى مختص | سؤال يطلب فتوى لحالة بعينها، أو حكمًا على شخص |

ويكشف أيضًا: الآية المنسوبة حديثًا (بالعربية والإنجليزية)، والآيتين المدموجتين في اقتباس واحد، والاقتباس الجزئي من الآية.

## كيف يعمل

1. **استخراج الادعاءات** من النص: الآيات بين ﴿ ﴾ أو { } أو ( ) أو بعد «قال تعالى»، والأحاديث بعد «قال رسول الله ﷺ» وما في معناها، بالعربية والإنجليزية.
2. **القرآن:** مطابقة كلمة بكلمة على فهرس محلي من مصحف حفص (6236 آية)، تتجاهل التشكيل واختلاف رسم الهمزات، وتتسامح مع الأخطاء الإملائية، وتعرض دائمًا نص المصحف الأصلي.
3. **الحديث، مساران مستقلان:**
   - **الدرر السنية:** بحث مباشر، ثم مطابقة كل رواية مع الاقتباس، وتجميع الروايات حسب الراوي، لأن الحكم يقع على الرواية لا على النص. تُقدَّم الرواية الصحيحة الأقرب للفظ، ويُذكر الصحيحان إن وُجدا. يُعدّ الحديث ثابتًا إذا كان في الصحيحين أو غلبت أحكام التصحيح، ولا يُحسم إذا غلب التضعيف مع وجود تصحيح.
   - **موسوعة الأحاديث النبوية:** فهرس محلي للمطابقة الحرفية بالعربية (3,574 حديثًا). وإذا قدّمت الدرر حكمًا من غير الصحيحين وتخريج الموسوعة يذكرهما، يُعرض ذلك في رأس النتيجة.
4. **الآيات المترجمة (الإنجليزية):** مطابقة كلمة بكلمة مع ترجمات موسوعة القرآن الكريم المعتمدة (رواد، ونور الدولية، والهلالي وخان)، ثم الرد إلى الآية العربية في المصحف، مع اسم الترجمة ورقم إصدارها.
5. **الأحاديث المترجمة (الإنجليزية): مطابقة بالمعنى.** للحديث الواحد ترجمات كثيرة، فلا تكفي المطابقة الحرفية. يُقسَّم كل حديث إلى جمل (من ترجمته المعتمدة ونصه العربي)، ويُقارن الاقتباس بها بنموذج تضمين متعدد اللغات يعمل داخل الخادم، ثم يُعرض الحديث وترجمته المعتمدة وحكمه كما هي في المصدر.
   - **تشابه عالٍ** ← «ثابت، ومطابق بالمعنى» مع نسبة التشابه.
   - **تشابه متوسط مع كلمة جوهرية مشتركة** ← «قريب في المعنى، يحتاج مراجعة».
   - **دون ذلك** ← لا يُنسب لأي حديث. وشرط الكلمة المشتركة يمنع نسبة قول مختلق إلى حديث يشبهه في المعنى: «Love of one's homeland is part of faith» يقارب في تشابهه صيغة صحيحة لحديث النية، لكنه لا يشارك أي حديث في كلمة جوهرية، فلا يُنسب إلى شيء.
   - المعايرة قابلة للتكرار: `node scripts/test-meaning.js`.
6. **الإحالة (المستوى د من المرجعية العلمية):** أسئلة الفتوى لحالة بعينها («هل يجوز لي…؟»، «طلقت… هل وقع؟») والحكم على الأشخاص لا يُجاب عنها، بل تُحال إلى جهة إفتاء معتمدة. ومحاولات تجاوز الحدود («تجاهل تعليماتك») لا تغيّر شيئًا.
7. **التقرير:** حالة كل ادعاء، والفرق كلمة بكلمة، والمصدر، وعبارة الحكم حرفيًا، وعدد أحكام التصحيح والتضعيف.

إذا تعذّر الوصول إلى مصدر، يُقال ذلك صراحةً، ولا يتحول أبدًا إلى «لم يُعثر عليه».

## المنهجية

طُبّقت منهجية بناء الطبقات المعتمدة في منصة lCaptainAI: لا يُعرض نص إلا بعد مطابقته حرفيًا مع مصدره. فكل طبقة (الاستخراج، ثم الاسترجاع من المصدر المعتمد، ثم المطابقة، ثم الحكم المنقول، ثم التقرير) تسلّم التي بعدها نتيجة يمكن تتبّعها إلى مصدرها.

## الاختبار

```
node scripts/test-suite.js
```

32 حالة تمر على خط المعالجة كاملًا (10 قرآن، و10 حديث، و7 محتوى مترجم، و5 إحالة)، ويُكتب التقرير في [doc/test-results.md](doc/test-results.md). ومنها حالات صُممت لتفشل لو أخطأ المنتج: قول مختلق يشبه حديثًا صحيحًا («من قرأ سورة الكهف يوم الأربعاء…»)، وآية منسوبة للنبي ﷺ، وعبارات حكم منفية («غير صحيح»، «ليس بثابت») كانت تُقرأ تصحيحًا قبل إصلاحها.

**عن الزمن في التقرير:** نتائج الدرر السنية تُحفظ مؤقتًا بعد أول تشغيل، احترامًا لحدود طلباتها، فمتوسط الزمن في التقرير لا يمثل الزمن الحي. أما على الرابط الحي فيتصل جِهْبَاذ بالدرر مباشرة مع كل حديث، فيكون الزمن أطول.

وسكربتات تشخيص لكل طبقة: `test-quran.js`، و`test-dorar.js`، و`test-meaning.js`، و`test-hadeethenc.js`، و`show-ayah.js`.

## المصادر والتراخيص

| المصدر | الاستخدام | طريقة الوصول |
| --- | --- | --- |
| [الموسوعة القرآنية](https://quranpedia.net) | نص المصحف (حفص) | النسخة الرسمية المنشورة، تُجلب أثناء البناء |
| [موسوعة القرآن الكريم QuranEnc](https://quranenc.com) | ترجمات معاني القرآن الإنجليزية المعتمدة | الواجهة الرسمية، تُجلب أثناء البناء؛ تُعرض دون تعديل مع اسم الترجمة ورقم إصدارها |
| [الدرر السنية](https://dorar.net) | أحكام الأحاديث | الواجهة البرمجية الرسمية للموسوعة الحديثية |
| [موسوعة الأحاديث النبوية](https://hadeethenc.com) | الأحاديث وترجماتها المعتمدة | الواجهة البرمجية الرسمية؛ المحتوى معروض دون تعديل مع ذكر المصدر |

بيانات المصادر لا تُرفع إلى هذا المستودع، وتُحمَّل بسكربتات الإعداد.

ملاحظة: حجم ملفات الموسوعة القرآنية مطابق بالبايت لما في `manifest.json`، لكن بصمة SHA-256 المنشورة لا تطابق الملف المضغوط ولا المفكوك، فيقبلها السكربت بعد التحقق من الحجم وسلامة الضغط، ويطبع البصمات للمراجعة.

## النشر

يُنشر على Railway من `Dockerfile`. فهرس المصحف وترجمات QuranEnc تُجلب وتُبنى أثناء البناء. وفهرس موسوعة الأحاديث يُحفظ على قرص دائم:

- قرص مركّب على `/data`
- `HADEETHENC_DIR=/data`
- `HADEETHENC_AUTOFETCH=1`: عند أول تشغيل يُجلب المحتوى ويُبنى الفهرس الحرفي ثم فهرس المعنى في الخلفية (قرابة ساعة ونصف)، والموقع يعمل خلال ذلك، وتظهر للمستخدم رسالة «قيد التهيئة». ويُحفظ نموذج التضمين على القرص نفسه.

## حدود معروفة

- المطابقة بالمعنى أضعف حين لا تكون للحديث ترجمة إنجليزية معتمدة في الموسوعة، فيُقارن الاقتباس الإنجليزي بالنص العربي مباشرة.
- إعادة صياغة الحديث العربي بالمعنى لا تُكتشف بعد، فالعربي يُطابق باللفظ.
- الآيات المنقولة بالإنجليزية تُطابق باللفظ مع ترجمات QuranEnc الإنجليزية؛ الصياغات الحرة لمعنى الآية لا تُطابق بعد.
- الاقتباس القصير جدًا المكوّن من كلمات شائعة قد لا يُعثر عليه.
- الإحالة تعتمد على صيغ السؤال الشائعة («هل يجوز»، «ما حكم»…)، فقد تفوتها صياغات نادرة.
- المطابقة على رواية حفص؛ وقد يظهر الاقتباس بقراءة متواترة أخرى «بلفظ مختلف» (سؤال مرفوع للمرشد الشرعي).

## خطوات قادمة

- **موسوعة المصطلحات الإسلامية (ICADB):** فحصنا واجهتها، فوجدنا 58 بطاقة معتمدة من 1,055، كلها في مصطلحات الحج. وأجّلنا الربط حتى تتسع البطاقات المعتمدة، لأن جِهْبَاذ لا يعرض إلا ما اعتُمد. والهدف: كشف المصطلحات المحمّلة في المحتوى المترجم («jihad»، «Sharia») مع مقابلها وتعريفها المعتمدين.
- **ترجمات الأحاديث بلغات أخرى** من بطاقات موسوعة الأحاديث في ICADB، لتوسيع التحقق من المحتوى المترجم إلى ما بعد الإنجليزية.
- **مسار ثالث للحديث** عبر خدمة MCP للمكتبة الشاملة.

## الإفصاح عن استخدام الذكاء الاصطناعي

- **في بناء المشروع:** استُخدم Claude (Anthropic) مساعدًا في كتابة الكود والتصميم والتوثيق، وراجع المشارك كل خطوة واختبرها.
- **داخل المنتج:** نموذج تضمين واحد مفتوح المصدر ([paraphrase-multilingual-MiniLM-L12-v2](https://huggingface.co/Xenova/paraphrase-multilingual-MiniLM-L12-v2)) يعمل داخل الخادم، دون أي خدمة ذكاء اصطناعي خارجية، ويُستخدم **للبحث بالمعنى فقط** في المحتوى المترجم. لا يُستخدم أي نموذج توليدي، ولا يُولَّد أي نص شرعي: كل ما يُعرض للمستخدم منقول من المصادر كما هو. أما الاستخراج والمطابقة الحرفية وتصنيف الأحكام فقواعد حتمية قابلة للتتبع.
